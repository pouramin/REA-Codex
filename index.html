STEP 02

Find an app.asar file

Many Electron applications bundle their resources into .asar archives. Not every application uses Electron or this file format.

Option 1 — Search with PowerShell

First check the common Xmind installation locations:

Check common Xmind paths
$paths = @(
  "$env:LOCALAPPDATA\Programs\Xmind\resources\app.asar"
  (Join-Path $env:ProgramFiles 'Xmind\resources\app.asar')
  (Join-Path ([Environment]::GetFolderPath('ProgramFilesX86')) 'Xmind\resources\app.asar')
)
$paths | Where-Object { Test-Path -LiteralPath $_ }

To find .asar files in common installation folders for other applications, use this command. The recursive scan may take a few minutes:

Search common app directories for ASAR files
$roots = @(
  (Join-Path $env:LOCALAPPDATA 'Programs')
  $env:ProgramFiles
  ([Environment]::GetFolderPath('ProgramFilesX86'))
) | Where-Object { $_ -and (Test-Path -LiteralPath $_) } | Select-Object -Unique

foreach ($root in $roots) {
  Get-ChildItem -LiteralPath $root -Filter *.asar -File -Recurse -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty FullName
}

FAQ
Things worth knowing

        

          
Can this page scan my entire PC for ASAR files?
No. Websites cannot access local files without permission. The picker only scans a folder you explicitly choose. PowerShell can search common installation locations.

          
Why does my app have no ASAR file?
ASAR is common in Electron apps, but not universal. Native Windows applications and differently packaged Electron apps may not use it.

          
Does REA recover all original source code?
No. Inventorying files, analyzing selected modules, and understanding behavior are not equivalent to recovering an entire application's original source code.

          
Is a Codex-built app the same as the original?
No. The goal is an independent implementation of selected features and an honest functional comparison—not a direct copy of the original program.
