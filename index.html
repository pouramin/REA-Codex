مرحله 01

آماده‌سازی و نصب

روی ویندوز، Node.js و Codex محلی رو آماده کن. بعد REA رو مستقیماً به Codex متصل کن.

Node.jsبرای اجرای REA با npx
Codexایجنت محلی با دسترسی به پروژه
REAابزار مهندسی معکوس و MCP
بررسی پیش‌نیازها
node -v
npm -v
نصب اتصال REA به Codex
npx.cmd rea-agents@latest setup --client codex
npx.cmd -y rea-agents@latest doctor --client codex --json
بعد از نصب، Codex رو کاملاً ببند و دوباره باز کن. نتیجهٔ healthy: true فقط ثبت تنظیمات رو تأیید می‌کنه؛ اتصال واقعی MCP باید داخل خود Codex تست بشه.

در Codex Desktop لازم نیست حتماً دستور codex در PowerShell نصب شده باشه. برای تحلیل جاوااسکریپتی یک بستهٔ Electron هم معمولاً موتورهای اختیاری تحلیل باینری مانند Ghidra لازم نیست.

مرحله 02

فایل app.asar رو پیدا کن

بسیاری از برنامه‌های Electron فایل‌های برنامه رو در بسته‌های .asar نگه می‌دارن. همهٔ نرم‌افزارها چنین فایلی ندارن.

روش ساده: دستور ویندوز

ابتدا محل‌های رایج نصب Xmind رو بررسی کن:

جست‌وجوی مسیرهای معمول Xmind
$paths = @(
  "$env:LOCALAPPDATA\Programs\Xmind\resources\app.asar"
  (Join-Path $env:ProgramFiles 'Xmind\resources\app.asar')
  (Join-Path ([Environment]::GetFolderPath('ProgramFilesX86')) 'Xmind\resources\app.asar')
)
$paths | Where-Object { Test-Path -LiteralPath $_ }

برای پیدا کردن بسته‌های .asar برنامه‌های مختلف در مسیرهای نصب رایج، از این دستور استفاده کن. ممکنه چند دقیقه طول بکشه:

پیدا کردن فایل‌های ASAR در مسیرهای رایج
$roots = @(
  (Join-Path $env:LOCALAPPDATA 'Programs')
  $env:ProgramFiles
  ([Environment]::GetFolderPath('ProgramFilesX86'))
) | Where-Object { $_ -and (Test-Path -LiteralPath $_) } | Select-Object -Unique

foreach ($root in $roots) {
  Get-ChildItem -LiteralPath $root -Filter *.asar -File -Recurse -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty FullName
}
جست‌وجوی فایل با کمک Codex

          
این پرامپت به Codex می‌گه فقط محل فایل رو پیدا کنه و قبل از شروع تحلیل متوقف بشه.

          
فایل app.asar یا پوشهٔ نصب برنامه رو فقط برای مطالعهٔ مجاز بررسی کن. فایل‌ها و دارایی‌های اختصاصی دیگران رو بدون مجوز منتشر نکن.

در Chrome یا Edge می‌تونی پوشهٔ نصب رو خودت انتخاب کنی. صفحه فقط اسم و مسیر نسبی فایل‌های .asar رو می‌بینه؛ آدرس کامل درایو رو مرورگر در اختیار سایت نمی‌ذاره.

پرسش‌های رایج
چند نکتهٔ مهم

        

          
آیا این صفحه می‌تونه کل کامپیوترم رو برای ASAR جست‌وجو کنه؟
نه. وب‌سایت بدون اجازه به فایل‌های سیستم دسترسی نداره. انتخابگر پوشه فقط محتوای پوشه‌ای رو بررسی می‌کنه که خودت انتخاب کنی. برای جست‌وجوی مسیرهای معمول نصب، از پاورشل استفاده کن.

          
چرا ممکنه نرم‌افزار من فایل ASAR نداشته باشه؟
ASAR قالب رایج بسته‌بندی برنامه‌های Electron هست، نه یک استاندارد همگانی برای تمام برنامه‌ها. برنامه‌های بومی ویندوز یا بعضی بسته‌بندی‌های دیگر ممکنه ASAR نداشته باشن.

          
آیا REA تمام سورس‌کد برنامه رو بازیابی می‌کنه؟
خیر. فهرست‌برداری، تحلیل فایل‌های انتخاب‌شده و استنتاج رفتار با بازیابی کامل سورس اصلی تفاوت دارن. محدودیت‌ها باید در گزارش نهایی مشخص باشن.

          
آیا پروژه‌ای که Codex می‌سازه همان برنامهٔ اصلیه؟
خیر. هدف ساخت یک پیاده‌سازی مستقل با برخی قابلیت‌های مشابه و ارزیابی مستند تفاوت‌هاست؛ نه کپی مستقیم نرم‌افزار اصلی.
